Agent 工具


    

    

    

    

      
get_project_context()

      

        
返回 projectId、editorRevision、引擎发布 release 和预览环境 preview。两项环境状态均可为 loading、available、failed 或 unsupported。可用时从 release.value 读取发布 ID 和引擎配置，从 preview.value 读取执行后端和呈现方式。失败时读取 error。

        
latestBuildAttemptId 指当前项目的最近构建。activeRunId 和 lastExitedRunId 跟随当前页面的预览，切换项目后仍可能指向先前项目。尚无记录的值为 null。

        
从 capabilities 查看工具在当前环境中的可用性。

      

      
check(input)

      
传入 projectId 和 expectedEditorRevision 做类型检查。返回 checkId、检查状态、sourceHash 和诊断。completed 表示收到检查结果，类型错误见 diagnostics。

      
get_diagnostics(input)

      
传入 projectId 和 editorRevision 读取已有诊断。用 checkId、attemptId 或 runId 指定记录，用 path 筛选条目。检查、构建和运行诊断分别返回。

      
play(input)

      
传入 projectId 和 expectedEditorRevision 开始构建与预览。接纳后返回 attemptId，由该 ID 查询构建或等待运行。

      
get_build({attemptId})

      

        
传入构建尝试 ID，读取项目与编辑版本、status 和 diagnostics。收到相应回执时还可读取 sourceHash、environmentFacts 和 compilerIdentity。构建状态有 pending、succeeded、failed、cancelled。有产物时，artifact 给出 variant、buildKey 和 artifactId。

        
diagnostics.observed 为 true 时有实测 counts，有效空列表的计数为零。为 false 时计数缺省。diagnostics.items 中的诊断可包含 code 和 location。omittedCount 表示省略的条数，单项的 omitted 表示正文未完整保留。构建或预览错误含 stage 和 diagnostic，已知错误码见 diagnostic.code。

        
preview.status 可为 not-requested（尚未请求）、preparing（准备中）、skipped（已跳过）、rejected（准备失败）或 session-created（已创建会话）。准备失败时读取 preview.error，创建会话后读取 preview.runId。预览调试不支持时 preview 可缺省。

      

      
get_run({runId})

      

        
传入运行 ID，读取运行身份、产物、发布与运行配置。用 attemptId 查关联构建。state 为 running 表示引擎已启动，项目就绪与首帧取决于相应观测。

        
observation 独立报告运行时查询的支持状态和就绪状态。supported: null 表示尚未确认，ready: true 后可查询节点。

        
exit 在收到退出回执后出现。exit.evidence 的 host-report 表示宿主回执，editor-local 表示页面兜底。exit.report 给出 reason，并保留来源提供的 engineOutcome、hostCleanup 和 sessionFacts。未观测到的原生退出码与清理字段可缺省。

      

      
read_run_events(input)

      

        
传入运行 ID，按页面接收顺序读取 items 中的 {seq, event}。kinds 筛选 state、log、project、exit，levels 只按 log、warn、error 筛选日志。limit 为 1–100，默认 50。

        
after 使用当前页面同一运行的 nextCursor。筛选后即使本页为空，游标也会越过已扫描记录。hasMore 表示当前还有未扫描记录，oldestAvailableSeq 为最早保留的序号，空缓冲时为 null。gap 给出已淘汰的序号范围，事件自己的 omitted 表示该条正文未保留。

      

      
wait_for_event(input)

      
传入 attemptId 或 runId 其中之一，并用 until 指定 running 或 exited。可设置 timeoutMs，也可通过第二个参数传入 AbortSignal 来取消等待。等待超时后可以用同一 ID 继续查询。

      
stop({runId})

      
请求停止指定的运行。返回 stopping 时，可等待 exited 取得终态与退出回执。

      
get_runtime_tree({runId, path?, depth?, limit?, timeoutMs?})

      
读取当前运行的节点树。省略 path 时从实际 SceneTree 根节点开始，通常为 /root。depth 默认 2，limit 默认 200。结果包含节点路径、类型、实例 ID 和截断状态。

      
inspect_runtime_node({runId, path, properties, timeoutMs?})

      
读取绝对节点路径的指定属性，支持 position、rotation、visible。节点缺失时返回 node_not_found。两种查询均返回运行身份、请求 ID 和采样序号，并可通过第二个参数 AbortSignal 取消。状态采样与 PNG 渲染提交分别计数。

      
screenshot({runId, timeoutMs?})

      
等待指定运行的新渲染提交，返回 PNG 字节、提交序号、采样几何与尺寸。Direct Worker 的支持状态见 get_run 的 interaction。

      
game_input({runId, gesture})

      
提交一次 key_tap（Space 或方向键）或 primary_click。点击坐标 x、y 以完整画布归一化到 [0, 1)，并传入截图的 geometry.epoch 作为 geometryEpoch。

      
wait_for_input({runId, operationId, timeoutMs?})

      
按操作 ID 读取按下和释放的分发事实。timeoutMs: 0 读取快照。等待超时可用同一 ID 再查。

    

    
schemaVersion 为 1。方法返回 {ok, result} 或 {ok, error}。失败构建的查询仍可成功，构建结果见 status。not_found 表示记录不可用，invalid_input 表示参数无效，invalid_cursor 表示游标无效。记录保存在当前标签页内存中，刷新页面会清除记录。
